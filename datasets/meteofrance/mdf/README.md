# Portail API Meteofrance :: Météo des Forêts (MDF)

https://www.data.gouv.fr/datasets/archives-de-la-meteo-des-forets

## Description

La Météo des forêts est un outil de prévention pour informer et sensibiliser le grand public face au danger que peuvent représenter les incendies au niveau départemental.

Les archives de la Météo des forêts sont disponibles à partir de 2024.


Les données de niveau de danger par département sont produites uniquement pendant la saison des feux, de début juin jusqu’à fin septembre sous forme de 2 cartes élaborées chaque jour à 17 h pour le lendemain (“J+1”) et le surlendemain (“J+2”).

Les niveaux y sont représentés sur une échelle de 1 à 4 :
* le niveau 1, vert, pour un danger météo des forêts faible à l'échelle du département
* le niveau 2, jaune, pour un danger météo des forêts modéré à l'échelle du département ;
* le niveau 3, orange, pour un danger météo des forêts élevé à l'échelle du département ;
* le niveau 4, rouge, pour un danger météo des forêts très élevé à l'échelle du département.
